# Fortune Cookie Wisdom for Developers


[Fortune Cookie Wisdom for Developers — make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)

A program that writes one original line of fortune-cookie wisdom for a
software developer to `/output/entry.txt` (77 characters, one line).

> The legacy code you curse today was once someone's proudest Friday afternoon.

Run it with Node 22+:

```sh
node main.ts
```
